WEBGL FUNDAMENTALS — EPISODE GUIDE
==================================

This guide covers the lessons in this repository, from Chapter 0 through
Chapter 20. The animation, physics, and collision curriculum continues in the
Sckorpio Real-Time WebGL repository:
https://github.com/SckorpioGraphics/sckorpio-real-time-webgl


PHASE 1 — WEBGL FOUNDATIONS
"From the first draw to reusable scene objects"
===============================================

CHAPTER 0 — SERIES INTRODUCTION
-------------------------------
0 - Introduces the series and its goals.

CHAPTER 1 — FIRST WEBGL DRAW
----------------------------
1a - Create a WebGL 2 context, compile and link shaders, configure vertex data,
     create a VAO, set the viewport, clear the canvas, and draw a triangle.

CHAPTER 2 — THE LESSON TEMPLATE
-------------------------------
2a - Introduce the series' object-centered code organization and the
     data-plus-behavior principle.
2b - Build a basic triangle using the cleaner lesson structure.

CHAPTER 3 — GEOMETRY AND INDEXING
---------------------------------
3a - Draw multiple triangles from one sequential vertex list.
3b - Build a rectangle from triangles with drawArrays().
3c - Reuse rectangle vertices with an index buffer and drawElements().
3d - Build indexed triangle geometry for a letter F.

CHAPTER 4 — PRIMITIVE TOPOLOGIES
--------------------------------
4a - Draw vertices as points with POINTS.
4b - Draw separate line segments with LINES.
4c - Connect vertices with LINE_STRIP.
4d - Close a connected sequence with LINE_LOOP.
4e - Draw a hexagon outline with LINE_LOOP.
4f - Generate and draw a circle outline with LINE_LOOP.
4g - Draw independent triangles with TRIANGLES.
4h - Build connected triangles with TRIANGLE_STRIP.
4i - Fill a hexagon using TRIANGLE_FAN.
4j - Generate and fill a circle using TRIANGLE_FAN.

CHAPTER 5 — DYNAMIC GEOMETRY
----------------------------
5a - Update triangle vertex data after creating its buffer.
5b - Edit rectangle vertices interactively.
5c - Generate and update a polygon outline.
5d - Generate and update a filled polygon.

CHAPTER 6 — VERTEX DATA AND COLOR
---------------------------------
6a - Use vertex values as color data and observe interpolation.
6b - Store position and color in separate buffers.
6c - Interleave position and color in one buffer.
6d - Observe interpolated colors across a two-triangle rectangle.
6e - Give the rectangle's triangles different vertex colors.

CHAPTER 7 — UNIFORMS
--------------------
7a - Pass a float uniform to control brightness.
7b - Pass color channels as separate float uniforms.
7c - Pass color as a vector uniform.
7d - Combine vertex color with a uniform color.
7e - Demonstrate uniform types and their upload methods.

CHAPTER 8 — MULTIPLE OBJECTS
----------------------------
8a - Draw a triangle and rectangle as separate objects with one shader.
8b - Organize drawing behavior on the objects themselves.
8c - Draw objects using different primitive topologies.
8d - Combine different objects, shaders, and color sources.
8e - Draw a grid and triangle with separate buffers and draw calls.


PHASE 2 — 2D COORDINATES AND TRANSFORMATIONS
"From clip space to a camera-based 2D world"
============================================

CHAPTER 9 — 2D SPACE AND CAMERA
-------------------------------
9a - Define geometry in pixel coordinates and map it to clip space.
9b - Introduce camera bounds and clip-space bounds.
9c - Invert the Y axis for pixel-space coordinates.
9d - Adjust camera and clip bounds to control the visible region.
9e - Map camera bounds to clip space with a camera object.

CHAPTER 10 — PROJECTION MATRIX
------------------------------
10a - Build a projection matrix in the shader.
10b - Build the projection matrix in JavaScript and pass it as a mat3 uniform.
10c - Render multiple pixel-space rectangles using the projection.
10d - Build a grid and axes using the projection matrix.
10e - Combine the grid, axes, and rectangle in the projected 2D world.

CHAPTER 11 — VIEW AND CAMERA CONTROL
------------------------------------
11a - Establish a 2D world with a grid and multiple objects.
11b - Represent camera state as data.
11c - Add camera zoom.
11d - Apply a view matrix for camera movement.
11e - Control the camera with keyboard input.
11f - Support continuous movement by tracking held-key state.

CHAPTER 12 — TRANSLATION
------------------------
12a - Translate an object by updating its geometry.
12b - Continue object translation with dynamic geometry.
12c - Pass translation values to the shader as uniforms.
12d - Represent the translation with a matrix.

CHAPTER 13 — ROTATION
---------------------
13a - Rotate an object with sine and cosine.
13b - Represent rotation with a matrix.
13c - Explore transformation order.
13d - Rotate around a selected pivot.

CHAPTER 14 — SCALE
------------------
14a - Apply scale directly to an object's geometry.
14b - Represent uniform and non-uniform scaling with a scale matrix.

CHAPTER 15 — MODEL MATRIX
-------------------------
15a - Combine translation, rotation, and scale in a model matrix.
15b - Pass a model matrix to the shader as a uniform.
15c - Apply independent model matrices to objects.
15d - Compose per-object model matrices with view and projection transforms.


PHASE 3 — TEXTURES AND ALPHA
"Give the 2D world image detail and transparency"
================================================

CHAPTER 16 — TEXTURES
---------------------
16a - Create and apply a first texture to a square.
16b - Reuse one texture on multiple objects.
16c - Assign different textures to different objects.
16d - Create and use procedural textures.

CHAPTER 17 — UV MAPPING
-----------------------
17a - Introduce UV coordinates and apply a texture to a square.
17b - Map a texture onto letter-F geometry with custom UVs.
17c - Map a texture onto a circle.

CHAPTER 18 — TEXTURE WRAPPING AND REPETITION
--------------------------------------------
18a - Extend UV coordinates beyond 0–1 and explore wrapping and repetition.
18b - Apply textures to multiple objects while retaining per-object texture state.
18c - Connect UV and S/T wrapping controls to the GUI.

CHAPTER 19 — TEXTURE FILTERING AND MIPMAPS
------------------------------------------
19a - Observe LINEAR magnification filtering.
19b - Compare NEAREST magnification filtering.
19c - Explore LINEAR minification filtering.
19d - Introduce mipmaps for differently sized textured objects.
19e - Continue the mipmap comparison across multiple object sizes.

CHAPTER 20 — ALPHA AND BLENDING
-------------------------------
20a - Establish opaque output when alpha is not supplied.
20b - Pass per-object alpha while blending is disabled.
20c - Enable blending so alpha affects the rendered result.
20d - Explain source-over alpha compositing and relate blending to render order.
20e - Apply an opaque Sckorpio texture.
20f - Add a transparent texture before enabling blending.
20g - Enable blending for transparent textures.
20h - Finish with transparent Sckorpio mascot and title textures.

SUPPLEMENTAL EXPERIMENTS
------------------------
`chapters/chapterExtra/chapterExtra1.js` explores an animated line and render
loop. `chapters/chapterExtra/chapterExtra2.js` renders random pixel-space
rectangles.

RUNNING
-------
Serve the repository root over HTTP and open http://localhost:8000:

    python3 -m http.server 8000

The default lesson is Chapter 20h. Change its module path in index.html to
select another lesson.
