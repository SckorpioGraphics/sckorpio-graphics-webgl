LESSON CODE ORGANIZATION
------------------------
The early lessons introduce WebGL operations directly, then progressively
organize related state and behavior into objects. The shared lesson pattern
keeps:

- shader state and program/location setup together
- camera dimensions and transformation state together
- geometry, GPU resources, and drawing behavior with their renderable objects
- application setup and scene drawing in an understandable sequence

The core principle is OBJECT = STATE + BEHAVIOR. The Chapter 10 lesson-template
notes in ../chapters/chapter10/chapter10a.js explain the convention and its
purpose.


RUNNING A LESSON
----------------
Serve the repository root over HTTP:

    python3 -m http.server 8000

Open http://localhost:8000. index.html currently loads
chapters/chapter25/chapter25g.js. To run another lesson, change the module path
in index.html to the desired chapter file. Some lessons also use the CDN-loaded
Lil GUI or gl-matrix libraries declared in index.html.
