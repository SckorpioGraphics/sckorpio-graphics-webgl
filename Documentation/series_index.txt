SCKORPIO GRAPHICS — WEBGL FUNDAMENTALS
======================================

This repository contains the introduction and foundation curriculum through
Chapter 20, including unified primitive topologies and separate lessons for UV
mapping and texture wrapping.

The optional `chapterExtra` folder contains supplemental pixel-space and
render-loop experiments.

CHAPTER 0 — SERIES INTRODUCTION
-------------------------------

PHASE 1 — WEBGL FOUNDATIONS
Chapters 1–8: First draw, lesson structure, geometry and indexing, primitive
topologies, dynamic geometry, vertex color, uniforms, and multiple objects.

PHASE 2 — 2D COORDINATES AND TRANSFORMATIONS
Chapters 9–15: Pixel and world coordinates, projection and view matrices,
camera controls, translation, rotation, scale, and model-matrix composition.

PHASE 3 — TEXTURES AND ALPHA
Chapters 16–20: Texture creation and reuse, UV mapping, texture wrapping and
repetition, filtering and mipmaps, alpha, blending, and transparent textures.

Chapters 21 and later, covering animation, movement, physics, and collision
detection, are in the Sckorpio Real-Time WebGL repository:
https://github.com/SckorpioGraphics/sckorpio-real-time-webgl

LESSON CODE ORGANIZATION
------------------------
Lessons remain self-contained JavaScript modules and progressively organize
related state and behavior into objects. The core principle is to keep state
and the behavior that manages it together. Shader objects own shader state,
mesh objects own geometry and GPU resources, and renderSystem owns canvas and
context setup and rendering. GUI and keyboard setup lives in appInit(); app()
handles one-shot frames and appLoop() handles lessons that need continuous
rendering. Each lesson uses only the systems it needs. Chapter 2a documents
the conventions with code examples:
chapters/chapter02/chapter2a.js

RUNNING A LESSON
----------------
Serve the repository root over HTTP:

    python3 -m http.server 8000

Open http://localhost:8000. index.html loads Chapter 20h by default; change
its module path to run another lesson. Lil GUI and gl-matrix are loaded from
CDNs declared in index.html.
